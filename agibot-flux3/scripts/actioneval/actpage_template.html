Does the model do what it is asked?

Score = judge verdict (completed yes 1, partial ½, no 0), averaged over the 3 seeds of a probe, then over probes; the band is the 95 % bootstrap interval over probes. Probes the real footage already passes are left out of these tiles (they cannot tell following the prompt from doing the usual action); the action table keeps them, marked ◆.

By how far training was from the prompt

The Caption Atlas exposure ladder, computed by parsing each probe's prompt against the 159,983 training captions.

The action index

Six actions from one start

Per start window: how many of its 6 prompts (own caption + 5 probes) the model completes on at least 2 of 3 seeds.

Start windows

Each grid plays the 6 prompts (rows) × seeds 0, 1, 2 (columns) from the same real start frame. Tags on the tiles are the judge's verdict on that clip. Right: the prompt of each row, its group and exposure level, and what the judge says the real footage does for that prompt.

How it was built

Actions

Start windows

Never-trained episodes of the val, test and test_unseen splits (test_unseen = the 5 held-out tasks), at the first labelled segment: the robot in its start pose, nothing grasped. Scene objects come from the episode's captions plus what Qwen3-VL-32B lists in the start frame.

Probes

Every action's template filled with every compatible scene object, re-parsed to check that it is new in the intended way, kept if the VLM finds it feasible in the start frame, then picked so each action has the same number of probes (3) in different tasks, and each window gets 5 probes with distinct verbs plus its own caption.

Scoring

Only the VLM judge: completed / attempted / plausible from 16 frames, real start frame first, arm ignored. No pixel metrics: the real footage shows one action and the probes ask for others. The real footage is judged against all 6 prompts to measure the judge (its own caption) and to flag probes the real action already satisfies.
