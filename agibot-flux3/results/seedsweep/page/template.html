Random-Depth Seed Sweep

Model random_depth_n1-8_long, trained with the loop depth drawn from 1–8 at every step. Each rollout starts from one real frame and chains 4 windows of 33 frames (8.8 s at 15 fps), every window conditioned on the model's own last frame. Every prompt is rolled out with 5 noise seeds. Seed 0 uses the same noise as the earlier single-seed Long Rollout pages, and every checkpoint and depth shares the same 5 seeds.
