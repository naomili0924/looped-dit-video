Changed Prompts

Start from a real frame of an unseen episode and ask for a different action in the same scene. The rollout mostly does the action the episode really contains, not the one in the prompt. Looping the core blocks more times (N = 1 to 8) does not change this.

This is expected from how the model was trained: each clip is paired with its own caption, and nothing in the objective makes the model act on a verb the scene does not already suggest. The examples below are the clearest cases. Each one plays the real episode, the rollout with the original caption, and the rollout with the changed prompt at N = 1 and N = 8, all from the same first frame and noise seed 0.

When a changed prompt does work

follows the change

Back away from the table

original
Move forward to approach the guest.
changed
Move backward away from the table.

This changed prompt is one of only two that appear word for word in the training captions, and here the robot does back away. That fits the reading above: the model follows instructions it has seen paired with motion, and otherwise falls back on what the scene suggests. The judge cannot tell forward from backward in this scene (it passes these clips against both prompts), so the evidence is the video.

Across all 25 cases

Qwen3-VL-32B judges each clip against the prompt it was made with and, as a cross check, against the other prompt. A model that follows its prompt gives changed-prompt clips a clearly higher score against the changed prompt than against the original caption. That gap stays at or below zero at every depth.
