Looped FLUX 3 Action on AgiBot

A FLUX 3 Action video model fine-tuned on AgiBot World Beta head-camera clips (k past frames + task caption → 33 future frames, 15 fps, 384×512), then retrofitted as a Looped-DiT whose 9 core blocks run N times per denoising step. Two evaluations, each a page with videos, cover every looped checkpoint we trained. Code and notes: naomili0924/looped-dit-video, folder agibot-flux3/.

say “normal eval”

Trained Loop Depth

Test split, 100 windows, k = 1 and 9, the model sampled at loop depth N = 1, 2, 4, 8: PSNR / SSIM / LPIPS, FVD (300 windows), a VLM judge, validation curves, the training recipe, and 8 fixed test windows as strips GT | base | fine-tuned | N = 1 | 2 | 4 | 8.

say “long-rollout eval”

Long Rollout

Zero-shot: one real frame and one prompt, four 33-frame windows chained autoregressively to 8.8 s. 8 test cases × 3 prompts (the real caption and two alternatives) × loop depths 1, 2, 4, 8, 16 next to the ground truth, the base model and the Phase-3 fine-tune.

How to run the evaluations

Both run on the box that holds the repo (two GPUs, the Phase-3 EMA and the Qwen3-VL text encoder under flux-action/outputs/weights); the full guide with prerequisites is EVAL.md. A checkpoint is named by a tag, its training step, its inference config and its EMA file (local or hf://user/repo/path).

# normal eval  (≈ 2.5 h on 2 H100s) → docs/loop-depth
HF_TOKEN=... scripts/normal_eval.sh <tag> <step> <config> <ema> ["label"] ["trained depths, e.g. 4"]

# long-rollout eval  (≈ 35 min on 2 H100s) → docs/long-rollout
HF_TOKEN=... scripts/run_long_rollout.sh <tag> <config> <ema>        # env: STEP, LABEL, TRAINED

# both end by rebuilding this site (scripts/build_pages.sh); publish it:
GH_TOKEN=... scripts/push_all.sh "agibot-flux3: eval of <tag>"

Models are registered in configs/models.json (tag, step, label, trained depths, config, weights); the wrappers add new tags automatically. Example for the random-depth model: scripts/normal_eval.sh rand2500 2500 configs/looped_ft_384_random_n1-8.json hf://Jinyan0924/flux3-agibot-looped/random_depth_n1-8/ema_step-2500.safetensors "random depth N 1–8, step 2500" 1,2,3,4,5,6,7,8.
